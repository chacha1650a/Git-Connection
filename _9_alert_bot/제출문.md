## Code 노드 언어 함정 (B4)

- **무슨 일이 있었나**: Code 노드 언어를 Python으로 바꾸고 실행했더니 에러 발생
- **원인**: 에러 메시지 `"Python runner unavailable: Python 3 is missing from this system"` — n8n 컨테이너 자체에 Python 3 런타임이 설치되어 있지 않아, Internal 모드에서는 Python 코드 실행이 원천적으로 불가능한 상태였음. (n8n 공식 문서 안내: Internal 모드는 디버깅용이고, 실제 운영에서 Python을 쓰려면 External Task Runner를 별도로 구성해야 함)
- **어떻게 해결했나**: 언어를 JavaScript로 전환. n8n Code 노드는 기본적으로 Node.js 기반이라 별도 설치 없이 즉시 동작함. 로직은 동일하게 `$input.all()`로 아이템을 순회하며 판정.

## 막혔던 것 · 해결

| 증상 | 원인 | 해결 |
|---|---|---|
| 게시판 저장 노드가 "연결 거부" | 게시판 Flask 서버(5000)가 꺼져 있었음 | `python app.py`로 서버 실행 |
| 게시판 저장이 400 | HTTP Request의 Body를 "Using JSON" 모드에서 각 값 앞에 `=`를 붙여, `{{ }}`가 문자 그대로(`=deny`) 전송됨 | 각 필드 값 앞의 `=` 제거, `{{ $json.xxx }}`만 남김 |
| IF 조건이 의도대로 안 갈림 | `value1`/`value2`에 복사하며 탭 문자가 섞여 들어감 | 칸을 비우고 깨끗하게 다시 입력 |
| 텍스트 필드가 비어서 나옴 | Set 노드가 예전 필드명(`ip`)을 참조 — 코드가 바뀌며 필드명이 `src_ip`로 변경됨 | 표현식을 `{{ $json.src_ip }}`로 수정 |
| Code 노드 이후 필드(`decision` 등)가 사라짐 | Set 노드의 "Include Other Input Fields" 토글이 꺼져 있었음 | 토글 켜기 |
